OPEN SOURCE CONTRIBUTION DAY WEBSITE

Files:
- index.html: complete single-file website with embedded CSS and JavaScript.

How to open:
1. Open index.html in any modern web browser.
2. The navigation links scroll to Home, About, Projects, Schedule, Register, and Contact.

Important:
- The registration form is a front-end demo. It validates fields and displays a confirmation message,
  but does not send or store registration data. A server/backend is required for real registration.
- Schedule, contact email, and venue are sample details. Edit them for your event.

Optional local server:
- Open a terminal in this folder and run: python -m http.server 8000
- Visit http://localhost:8000
